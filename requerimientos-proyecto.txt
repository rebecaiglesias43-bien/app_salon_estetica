📋 Requerimientos Funcionales (RF)
1. Gestión de Acceso (Seguridad)

RF01: El sistema debe tener un único acceso privado protegido por usuario y contraseña (Administrador).

RF02: El sistema debe permitir al administrador cambiar su contraseña.

2. Módulo Público (Landing Page para Clientes)

RF03: El sistema debe mostrar una página web pública con la información del salón y los servicios ofrecidos.

RF04: El sistema debe contar con un formulario donde los clientes puedan solicitar una cita (ingresando su nombre, teléfono, servicio deseado y fecha/hora).

3. Módulo de Citas (Panel Admin)

RF05: El sistema debe recibir y listar las solicitudes de citas enviadas desde la página pública.

RF06: El administrador debe poder aprobar, rechazar, reprogramar o cancelar las citas.

RF07: El sistema debe permitir al administrador agendar una cita manualmente (por si un cliente llama por teléfono).

4. Módulo de Clientes

RF08: El sistema debe permitir registrar, editar, eliminar y consultar la información de los clientes (Nombre, Teléfono, etc.).

RF09: El sistema debe guardar y mostrar el historial de servicios que se le han realizado a un cliente específico.

5. Módulo de Catálogos (Servicios e Inventario)

RF10: El sistema debe permitir registrar los servicios del salón (Ej. Corte, Tinte) con su precio y duración aproximada.

RF11: El sistema debe permitir registrar los productos físicos (Inventario) que se usan o venden en el salón.

RF12: El sistema debe permitir consultar la cantidad disponible (stock) de cada producto en tiempo real.

6. Módulo de Proveedores y Compras (Egresos)

RF13: El sistema debe permitir registrar y gestionar los datos de los proveedores.

RF14: El sistema debe permitir registrar las compras de insumos realizadas a los proveedores.

RF15: Al registrar una compra, el sistema debe sumar automáticamente la cantidad de los productos comprados al Inventario.

7. Módulo de Ventas (Ingresos)

RF16: El sistema debe permitir registrar la venta de un servicio o producto a un cliente.

RF17: Al registrar una venta que implique uso de productos, el sistema debe restar automáticamente la cantidad de esos productos del Inventario.

8. Módulo de Finanzas y Cortes de Caja

RF18: El sistema debe calcular y mostrar el total de Ingresos (Ventas) y el total de Egresos (Compras).

RF19: El sistema debe mostrar la ganancia real (Ingresos menos Egresos).

RF20: El sistema debe permitir realizar un "Corte de Caja" (diario, semanal o mensual) para cerrar un periodo y reiniciar los contadores para el siguiente, guardando el historial de ese corte.

🎨 Requerimientos No Funcionales (RNF) - (Cómo debe ser el sistema)
RNF01: La interfaz visual tanto del panel de administración como de la landing page debe usar tonos pasteles (como tenías pensado originalmente).

RNF02: El sistema debe ser responsivo (que el administrador pueda usar su panel desde el celular sin que se vea deforme).

RNF03: La base de datos debe ser relacional (MySQL/PostgreSQL) para asegurar la integridad entre inventario, compras y ventas.
